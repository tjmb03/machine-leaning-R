# Machine Learning & Statistical Modeling in R

Applied statistical modeling and reproducible data analysis workflows in R.

This repository demonstrates foundational quantitative skills supporting advanced work in multi-omics, PK/PD modeling, and translational data science.

---

## Contents

### 📄 clt_exponential_report.Rmd  
Simulation study of the Central Limit Theorem using exponential distributions.  
Focus: sampling distributions, convergence to normality, simulation-based inference.

### 📄 motortrend_report.Rmd  
Linear regression analysis using the `mtcars` dataset.  
Focus: model comparison, coefficient interpretation, statistical inference.

### 📄 toothgrowth_analysis.Rmd  
Hypothesis testing and confidence interval analysis using experimental data.  
Focus: treatment effects, group comparisons, statistical reporting.

---

## Capabilities Demonstrated

- Statistical simulation  
- Linear regression modeling  
- Hypothesis testing  
- Confidence interval estimation  
- Data visualization  
- Reproducible reporting with R Markdown
